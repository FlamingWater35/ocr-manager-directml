# Transitive pins for the bundle. There is no first-run install any more: the
# whole OCR stack (RapidOCR + onnxruntime-directml) is inside this tree, so the
# bundle alone decides which version runs. Every entry below is in the
# dependency closure of packaging/requirements-bundle.txt, and every version
# here AGREES with that file -- the two are resolved together, so a pin that
# contradicts requirements-bundle.txt makes `pip install -c` fail with
# ResolutionImpossible before a single wheel is downloaded. That is exactly
# what happened to this file before: it had been frozen from a different venv
# (numpy 2.5.4 here vs 2.4.1 there, mpmath 1.4.1 here vs sympy's own
# `mpmath<1.4` requirement), and the release build could not get past
# install_dependencies().
#
# Refresh with the target interpreter rather than a dev venv, and let pip do
# the resolution so the two files cannot drift apart:
#   python -m pip install --only-binary=:all: --dry-run --report report.json \
#       -r packaging/requirements-bundle.txt
#   # then rewrite this file from report.json's `install` entries
